# Нервион

![Нервион: трекер для IT-агентств, канбан и карточка задачи на компьютере и телефоне](docs/images/cover.png)

Нервион помогает IT-студиям и digital-агентствам вести клиентские проекты от сделки до отчёта. Команда работает с задачами на канбане, обсуждает их в чатах и голосовых комнатах. Аккаунт-менеджер ведёт сделки в CRM, переписывается с клиентом по почте и выгружает в Excel подробный отчёт о выполненных работах. Трекер с открытым кодом можно установить на своём сервере.

## Клиентские проекты

### Доска задач

![Канбан с задачами по клиентским проектам](docs/images/overview/kanban.webp)

Переключайтесь между канбаном, списком задач и недельным видом. Настраивайте этапы, фильтруйте задачи по проекту и ответственному, оценивайте объём работы в Story Points.

### Карточка задачи

<img src="docs/images/overview/task.webp" alt="Карточка задачи с подзадачами и комментариями" width="560" />

Разбивайте работу на подзадачи, назначайте ответственных и сроки, связывайте задачи между собой. Обсуждение и история изменений остаются в карточке. Черновик задачи можно надиктовать и оформить с помощью ИИ.

### CRM

![Воронка сделок в CRM](docs/images/overview/crm.webp)

Ведите сделки по этапам и храните компании и контакты в CRM. Привязывайте задачи к сделкам, а для выигранной сделки создайте проект или выберите существующий.

### Проекты и бюджеты

![Список клиентских проектов с бюджетами](docs/images/overview/projects.webp)

Задавайте месячный бюджет и почасовую ставку для проекта. Сравнивайте бюджет с выработкой команды по учтённому времени.

## Общение и документы

### Чаты

![Чаты и список голосовых комнат](docs/images/overview/chat.webp)

Обсуждайте проекты в личных и групповых чатах, отправляйте файлы и голосовые сообщения. О новых сообщениях и упоминаниях приходят push-уведомления.

### Голосовые комнаты

![Настройка состава голосовой комнаты](docs/images/overview/voice.webp)

Создавайте комнаты для рабочих групп, выбирайте участников, созванивайтесь и показывайте экран.

### Встроенная почта

![Почтовые папки и форма нового письма](docs/images/overview/mail.webp)

Ведите переписку с клиентами внутри трекера. В почте есть папки, цепочки писем и вложения.

### Календарь

![Календарь встреч команды](docs/images/overview/calendar.webp)

Назначайте встречи и приглашайте участников. В календаре видны события команды на неделе.

### База знаний

![Дерево страниц и открытый документ в базе знаний](docs/images/overview/wiki.webp)

Храните регламенты, документацию проектов и материалы для новых сотрудников в дереве страниц. В редакторе есть таблицы и чек-листы, файлы можно хранить в S3.

## Учёт времени и отчёты

### Учёт времени

![Отчёт по затраченному времени в карточке задачи](docs/images/overview/timer.webp)

Запускайте таймер прямо из задачи или вносите часы вручную. Записи о времени попадают в отчёты и в фактическую загрузку команды.

### Отчёты

![Сводка выработки и бюджетов в разделе отчётов](docs/images/overview/report.webp)

Смотрите, сколько времени ушло на каждый проект и кто выполнял задачи. Для клиента выгружайте в Excel сводку или детализацию с описаниями задач.

### Планирование загрузки

![Недельное планирование загрузки по людям и проектам](docs/images/overview/planning.webp)

Распределяйте часы по людям и проектам на неделю. Переключайтесь между планом и фактом, чтобы видеть, где команда уже занята.

### График работы

![График работы сотрудников](docs/images/overview/schedule.webp)

Настраивайте рабочие интервалы сотрудников. График помогает увидеть, кто доступен в конкретный день и время.

## Инструменты и доступ

### Git-репозитории

![Список коммитов и изменения в файле](docs/images/overview/git.webp)

Привязывайте репозитории к проектам. Смотрите дерево файлов, историю коммитов и изменения кода прямо в Нервионе.

### Мониторинг сайтов

![Список проверок доступности сайтов](docs/images/overview/monitoring.webp)

Следите за доступностью клиентских сайтов и сервисов. Задавайте интервал, таймаут и ожидаемый HTTP-статус, отправляйте уведомления о сбоях в чат.

### Роли и пользователи

![Список пользователей и их ролей](docs/images/overview/roles.webp)

Назначайте роли и управляйте доступом к проектам. Архивируйте учётные записи с сохранением истории задач и записей времени.

### Журнал действий

![Журнал действий с фильтрами и деталями события](docs/images/overview/audit.webp)

Смотрите, кто и когда менял задачи, проекты и пользователей. Детали события показывают состояние до и после изменения. Для анонсов команде есть раздел "Что нового".

## Запуск на своём сервере

Используйте [инструкцию по установке через Docker Compose](./docs/self-hosted.md). Она описывает настройку администратора, запуск PostgreSQL, API и веб-приложения.

Для разработки есть [инструкция по локальному запуску](./docs/development.md). Интерфейс написан на Nuxt 3 и Vue, API на NestJS с PostgreSQL. После запуска документация API доступна по адресу `http://localhost:3026/api/docs`. Для интеграций есть [описание CRM API](./docs/crm-api.md).
