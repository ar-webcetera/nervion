# Документация и changelog

## Changelog

- Значимые изменения поведения системы, конфигурации, интеграций, запуска,
  эксплуатации, безопасности или документации сопровождайте обновлением
  `CHANGELOG.md`.
- Если меняются код, env-шаблоны, инструкции по запуску или публичная
  документация, обязательно проверьте необходимость обновления `CHANGELOG.md`.
- Без обновления changelog задачу нельзя считать завершённой, если нет явной
  причины, почему запись не нужна.

## Проектная документация

- При изменении поведения проекта обновляйте релевантные разделы `README.md`.
- Новые конфигурации, переменные окружения и сценарии запуска отражайте в
  документации.
