# Публикация и эксплуатационные действия

- Не выполняйте push, деплой, публикацию релиза, перезапуск процессов и другие
  действия во внешних системах без отдельного явного запроса пользователя.
- Перед разрешённым действием проверьте целевой remote, ветку и ожидаемые
  побочные эффекты.
- Не добавляйте в публичную документацию адреса серверов, внутренние пути,
  имена закрытых remote, схему деплоя, учётные данные и другие сведения о
  внутренней инфраструктуре.
