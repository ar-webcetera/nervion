# Frontend

- Эталон вёрстки и правила интерфейса —
  [`docs/design-system.md`](../design-system.md). Новые разделы верстайте по
  нему.
- В Vue/Nuxt компонентах и страницах по умолчанию используйте `scoped`-стили.
- Нескоупленные стили допустимы только для глобального эффекта или
  переопределения внешней библиотеки.
- Начальные данные страницы загружайте на этапе SSR через `await useAsyncData` или
  `await useFetch`. Не переносите первичную загрузку в `onMounted`: клиентские
  запросы допустимы только для последующего обновления данных и действий
  пользователя. Для авторизованных SSR-запросов передавайте входящий `cookie`
  через `useRequestHeaders(['cookie'])` и используйте SSR-aware `useApiBaseUrl()`.
