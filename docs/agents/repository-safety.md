# Безопасность и гигиена репозитория

- Не коммитьте секреты, реальные env-файлы, логи, приватные заметки и локальные
  рабочие артефакты.
- Перед коммитом проверяйте staged diff на случайное попадание чувствительных
  данных и локальных файлов.
- При риске утечки секрета явно укажите на него в результате работы.
